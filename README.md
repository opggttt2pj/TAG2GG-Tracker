# TAG2.GG Tracker

Tekken Tag Tournament 2 온라인 대전 기록 추적 프로그램입니다.

## 주요 기능

- RPCS3 기반 온라인 대전 자동 감지
- 대전 결과 및 플레이어 정보 기록
- TAG2.GG 통계 사이트 데이터 연동
- 프로그램 버전 및 업데이트 확인
- 구버전 및 인터넷 연결 오류 안내

## 사용 방법

1. RPCS3를 실행합니다.
2. Tekken Tag Tournament 2를 실행합니다.
3. 최신 버전의 `TAG2GGTracker.exe`를 다운로드합니다.
4. 프로그램을 실행한 상태로 온라인 대전을 진행합니다.

## 주의사항

- RPCS3와 Tekken Tag Tournament 2가 실행 중이어야 합니다.
- 온라인 대전만 기록됩니다.
- 프로그램은 시작할 때 GitHub 연결 및 최신 버전을 확인합니다.
- 인터넷 연결 또는 GitHub 확인에 실패하면 실행되지 않습니다.
- 구버전은 자동으로 실행이 차단될 수 있습니다.
